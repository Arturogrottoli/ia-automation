El Problema que Resuelve JSON

Sin estructura

Una app manda "Juan Pérez, 30 años, Madrid".

Otra espera "Nombre: Juan | Ciudad: Madrid | Edad: 30".

Resultado: no se entienden.

Receta estructurada

{ "plato": "Bizcocho", "ingredientes": ["harina", "huevos", "sal"], "temperatura": 180, "tiempo_minutos": 45 }

Si Make necesita el tiempo, busca la etiqueta tiempo_minutos.

Variables y Mapeo

No escribas datos fijos si cambian en cada ejecución
  • Una variable es una caja etiquetada: hoy dice "Ana", mañana "Carlos". En Make son las burbujas de colores.
  • En vez de "Hola Juan", usás {{1.Nombre}}: un solo flujo sirve para miles de casos.
  • Mapeo: llega {"email": "cliente@ventas.com"} → elegís la burbuja email en el campo de Airtable.

Guía de supervivencia

Comillas perdidas: {nombre: "Luis"}. Coma final: {"id": 1,}. Texto vs número: "10" + "10" puede dar 1010; usá parseNumber().

Tu API Key de OpenAI, Paso a Paso

  • platform.openai.com (no es la web de ChatGPT) → perfil → API keys → Create new secret key.
  • La clave (sk-...) se muestra una sola vez: copiala y guardala.
  • Billing: cargar saldo mínimo y definir un límite de gasto. Se paga aparte de ChatGPT Plus.
  • En Make: Create a Chat Completion → Connection → Add → pegar la key.

Tratala como una contraseña

No la pegues en chats ni archivos compartidos. Error 401 = clave mal copiada o cuenta sin saldo. Si se filtra, revocala y generá otra.

El Prompt Tiene que Devolver una Palabra Exacta

System

"Eres un clasificador de leads. Analizas el mensaje del cliente y respondes ÚNICAMENTE con una de estas dos palabras, sin explicaciones ni puntuación: Alta o Baja."

User

"Clasifica la prioridad de este lead según su intención de compra: " + la variable del mensaje.

Filtros: Respuesta = Alta y Respuesta = Baja.

Si la IA responde "Creo que este lead es importante", el filtro no encuentra coincidencia y el flujo se rompe. Max Tokens: 100–200 para clasificar.

Los 4 Error Handlers de Make

HandlerQué haceCuándo usarlo
RollbackFrena y deshace todo (es el de defecto)La opción conservadora
IgnoreIgnora el error y sigueSolo si el paso no es crítico
BreakReintenta después de un tiempoLa joya de la corona. La PE3 lo exige
ResumeSigue con un valor sustitutoPara que los módulos siguientes no fallen

Clic derecho sobre el módulo → Add error handler → aparece una rama gris que solo se activa si ese módulo falla.

Reintentos: el Repartidor de Pizzas

Sin manejo de errores

Nadie abre a la primera, tira la pizza y se va. Perdés la pizza y la plata.

Con Break

Espera y vuelve a tocar el timbre. Lo intenta 3 veces antes de rendirse.

Con plan B

Si nadie abre, deja la pizza en recepción (ruta alternativa) y te avisa.

Backoff exponencial: 1 minuto, 5, 15. Veinte reintentos por segundo solo gastan operaciones.

CODERHOUSE

No Todos los Errores Merecen un Reintento

Error 401 — No autorizado

La API key está mal. Reintentar 100 veces no lo arregla.

Alerta inmediata a Slack o mail.

Error 500 — Error del servidor

Un problema temporal del otro lado.

Acá los reintentos son obligatorios.

Toda rama de error termina con una notificación para vos: mejor un aviso a tiempo que un cliente ignorado una semana.
