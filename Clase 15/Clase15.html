Tema 01

Qué Hay que Construir

Un ecosistema funcionando en vivo que resuelva un proceso de negocio de punta a punta: gestión de leads, atención al cliente con memoria, propuestas comerciales o un pipeline de contenido.

CODERHOUSE
06 / 18

Las 4 Categorías de Tecnología (Todas Obligatorias)

Orquestador

n8n (preferido) o Make.

Base de datos

Airtable o Notion, como memoria y registro.

Procesamiento IA

OpenAI o Claude, con prompts estructurados y, mejor, agentes o RAG.

Canal de salida

Gmail, Slack o WhatsApp API.

CODERHOUSE
07 / 18

Requisitos de Arquitectura

  • Se dispara, procesa datos con IA desde la base y entrega un output sin intervención manual.
  • Rutas de error ante datos faltantes o fallos de API.
  • Un punto de validación humana (HITL) antes de una acción crítica.
  • Nodos con nombres claros, variables dinámicas y nada hardcodeado.

La Hoja de Ruta en 6 Pasos

Del caso de uso a la entrega: Cerebro, Corazón, semáforo humano y Voz. Cada paso reutiliza algo que ya construiste.

Pasos 1 y 2: Caso de Uso y Cerebro

1 · Elegí tu caso de uso

Un proceso propio o de un cliente ficticio que necesite interpretar lenguaje natural.

Para la mayoría: el proceso que vienen trabajando desde el Módulo 1.

2 · Estructurá el Cerebro

En Airtable o Notion, con campos de estado obligatorios: Pendiente, Procesado por IA, Aprobado por humano.

Relaciones entre tablas para no tener datos aislados.

CODERHOUSE
13 / 18

Pasos 3 y 4: el Corazón y el Semáforo Humano

3 · Construí el Corazón

Trigger inteligente: "From now on" o webhooks, para no gastar operaciones.

Motor de IA: mapear bien la respuesta y limitar Max Tokens.

Error handling obligatorio: si la API falla, se guarda un registro del error.

4 · Implementá el HITL

Para evitar el efecto metralleta, el flujo se detiene antes de la acción crítica.

Una notificación de aprobación (Slack o Email) antes de contactar al cliente.

Check de Seguridad Antes de Enviar

¿Hay filtro anti-bucles?

Que un flujo no se dispare a sí mismo ni responda a respuestas automáticas.

¿Tipos de datos correctos?

Los filtros comparan número con número, no texto con número.

¿Prompt dinámico?

El prompt usa variables del sistema; nada escrito a mano.
