Google Sheets y Airtable: Aliados, no Rivales

Airtable → Sheets (salida): fácil

Con las Automations de Airtable: trigger "cuando un registro cumple una condición" (Status = Finalizado) → acción "Google Sheets: Append row".

Ej.: cada proyecto finalizado se suma al Sheet del contador.

Sheets → Airtable (entrada): la puerta unidireccional

Airtable es una oficina con una puerta que solo abre hacia afuera. Para que entre información sola hace falta un "cartero".

No hay sincronización bidireccional nativa y gratuita.

Herramientas Puente: los "Carteros" de Datos

Whalesync

La favorita para sincronización bidireccional: cambiás algo en un lado y cambia en el otro.

Byteline

Simple para freelancers que conectan tablas de clientes sin complicaciones.

Data Fetcher

Extensión de Airtable que trae datos de Sheets bajo demanda.

Para mandar datos nuevos: automatizaciones internas. Para dos archivos espejo: una herramienta externa.

El Poder del Prompt en Omni AI

Prompt vago

"Hazme una base de datos para mi negocio."

Resultado: algo genérico que probablemente no sirva.

Prompt profesional

"Crea una base para un negocio de coaching. Tabla de Clientes (email y teléfono), tabla de Sesiones (fecha, notas, status de pago) y tabla de Paquetes de Horas. Conecta las sesiones con los clientes y agrega una vista de calendario."

Usá guardrails: decile los estados exactos ("En Proceso", "Pausado", "Terminado") para que cree el Single select como lo necesitás.

Proyecto ejemplo · prompt a Omni AI

Después de generar: revisar que el presupuesto sea número o moneda y que los estados estén como los pedimos.

Por Qué Ahora: la Cocina Profesional

  • Programación tradicional: cultivar los vegetales y fabricar los cuchillos antes de cocinar.
  • Low-Code: ingredientes pre-cortados y salsas base, pero hace falta técnica.

Ejemplo: el JSON de una Consulta

{ "consulta_id": "C-0042", "nombre": "Ana Pérez", "email": "ana@mail.com", "fecha_entrada": "2027-01-10", "fecha_salida": "2027-01-17", "huespedes": 4, "presupuesto_por_noche": 120000, "prioridad": "Alta", "propiedades_sugeridas": [ {"nombre": "Cabaña Los Coihues", "capacidad": 4}, {"nombre": "Depto Centro Cívico", "capacidad": 5} ] }

  • Un array de objetos: las propiedades sugeridas.
  • Números sin comillas; texto con comillas dobles.
  • Validado en jsonlint antes de entregar.
